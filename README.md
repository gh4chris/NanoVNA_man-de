## Technische Hinweise zu diesem Repository

Dieses Repository ist für die Veröffentlichung über GitHub Pages vorgesehen. Die Inhalte werden mit Jekyll in statische HTML-Seiten umgewandelt.

## Lokale Vorschau

### Voraussetzungen

Für eine lokale Vorschau werden folgende Programme benötigt:

- Ruby
- Bundler

Falls der Befehl `bundle` noch nicht verfügbar ist, kann Bundler mit folgendem Befehl installiert werden:

```bash
gem install bundler
```

### Lokalen Webserver starten

Der lokale Jekyll-Webserver wird im Hauptverzeichnis des Repositorys mit folgendem Befehl gestartet:

```bash
bundle exec jekyll serve
```

Anschließend ist die Dokumentation im Webbrowser unter folgender Adresse erreichbar:

[Lokale NanoVNA-Dokumentation öffnen](http://localhost:4000/NanoVNA-manual/)
